Bantuan

Masalah yang sering muncul dan cara mengatasinya.

Data tidak muncul atau terasa lama
  • Pastikan ada internet.
  • Buka Pengaturan, tekan Tes koneksi.
  • Bila masih lama, tekan Muat ulang dari server.
"Token salah" atau akses ditolak

Token di HP berbeda dengan token di server. Di editor Apps Script jalankan infoKoneksi, salin token terbaru, lalu isi di Pengaturan. Bila token pernah diganti lewat buatTokenBaru, semua HP harus diperbarui.

Catatan "Gagal dikirim"

Server menolak catatan itu, biasanya karena isinya tidak valid. Buka Pengaturan, bagian Pengiriman data. Perbaiki lewat aplikasi, atau tekan Buang yang gagal bila tidak diperlukan.

Aplikasi tidak memuat versi terbaru

Buka Pengaturan, tekan Segarkan aplikasi (perlu internet). Bila Anda mengubah file aplikasi, naikkan angka VERSI di sw.js sebelum mengunggah.

Pasang di layar utama

Android (Chrome): menu titik tiga, Pasang aplikasi. iPhone (Safari): tombol Bagikan, Tambah ke Layar Utama.

Pindah ke HP baru

Di HP lama buka Pengaturan, Salin kode sambung. Di HP baru tempel kode itu lalu tekan Pakai.

Info untuk teknisi

Salin lalu kirim bila meminta bantuan. Tidak berisi token.
